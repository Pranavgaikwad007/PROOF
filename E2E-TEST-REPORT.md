## 2. Outstanding Issues or Known Limitations

- **Browser Subagent Playwright Download**: During automated headless browser execution, the remote Playwright driver download encountered a temporary 404 from the CDN provider (`playwright.azureedge.net` for `mac-arm64`). Full UI and runtime verification was performed via Vite production compiler (`tsc --noEmit && vite build`), local HTTP 200 curl verification of frontend and backend endpoints, and component test inspection.
- **Backend Persistence**: When running with SQLite, restarting the database process can require re-running `npm run seed` if the SQLite database file is wiped. The fallback in `src/data/assessment.ts` ensures complete zero-downtime offline resilience.
